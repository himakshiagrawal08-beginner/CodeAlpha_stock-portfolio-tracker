# Stock Portfolio Tracker 📈

A Python-based stock portfolio tracker built during my Python Development 
Internship at CodeAlpha.

## Features
- Input stock ticker and quantity
- Hardcoded price dictionary for instant lookup
- Calculates total investment value
- Exports report as .CSV or .TXT file

## Concepts Used
- Python Dictionaries
- User Input & Output
- Basic Arithmetic
- File Handling

## How to Run
```bash
python portfolio.py
```
